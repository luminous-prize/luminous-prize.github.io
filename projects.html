Canadian Market Analysis — Agentic RAG over Earnings Transcripts

Johns Hopkins · Agentic AI · Financial NLP · Retrieval Systems

Built an agentic Retrieval-Augmented Generation (RAG) system for structured financial reasoning over Canadian earnings call transcripts. The platform routes analyst-style questions through a stateful LangGraph workflow combining semantic retrieval, SQL aggregation, sentiment analysis, topic modeling, and self-correcting synthesis loops.

  • Processed 83 earnings call transcripts across 13 major Canadian equities spanning Q2 2024 – Q1 2026
  • Built a LangGraph agent with routing, retrieval grading, hallucination detection, and reformulation loops
  • Integrated PostgreSQL + pgvector semantic retrieval using 768-D local embeddings
  • Replaced LDA with BERTopic for stable topic discovery and cleaner financial topic separation
  • Implemented speaker-aware chunking enabling management-vs-analyst sentiment gap analysis
  • Added sector-aware ticker resolution ("Canadian banks" → RY, TD, BNS)
  • Combined FinBERT sentiment scoring with OpenRouter synthesis pipelines

LangGraph · PostgreSQL · pgvector · BERTopic · FinBERT · FastAPI · Ollama · OpenRouter · Docker

  • Automated structured extraction from 99 papers using Anthropic Haiku
  • Achieved sub-$0.002 average query cost at mid-budget inference settings
  • Generated fully cited synthesis outputs with section-level grounding
